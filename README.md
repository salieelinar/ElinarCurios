# Elinar Curios

基于GTNH（Minecraft 1.7.10）的私货模组，一些零零碎碎自用的小物品和提升体验的修改。
有关机器配置可输入 /Elinar 查看说明
本mod正准备将id迁移至23100-23199

## 无限背包

- 243 格，单格上限 2,147,483,647（Integer.MAX_VALUE），自动合并、溢出安全
- 500×276 无限箱风格界面，数量按 K / M / B 显示
- 可穿在背上（自带龙形背包皮肤），穿戴时提供夜视，可在界面里开关
- 快捷键 `B` 打开背包，可在「控制」里改键
- 自带神奇的效果

## 和平图腾

- 放在任意实心方块上，阻止周围椭球范围内自然刷怪（默认水平 64 / 垂直 32）
- 刷怪笼、刷怪蛋、`/summon` 不受影响

## GTNH 相关方块

| 方块 | 作用 |
|---|---|
| 天玄虚空能量节点 | 缓存线缆 EU 并注入无线电网 |
| 样板总成镜像（物品 / 流体） | 贴在装配线输入总成位置，用数据棒绑定样板总成，零管道直供 |
| 高级装配线 | 原版装配线结构的 1:1 克隆，支持多安 / 激光能源仓与 GTNL 并行控制仓 |
| 可调式流体输入仓 | 容量可在 1 ~ 2,147,483,647 L 之间设置；进 GUI 点左下角螺丝刀按钮改，调低会销毁超出的流体 |
| 菲涅尔透镜 | 让反应堆内每个增殖单元均匀受中子辐照 |

### 束流轮椅一条龙（新增）

| 方块 | 作用 |
|---|---|
| 束流虚空存储器 | 单方块，存 19 种粒子，每种上限 `Long.MAX_VALUE`；本方案核心 |
| 束流虚空输入仓 | 装在多方块的束流输出位（源室 / 强子对撞机），把粒子收进虚空存储器；闪存绑定存储器 |
| 束流虚空输入室 | 输入仓的单方块版：正面接束流管，粒子收进虚空存储器；闪存绑定存储器 |
| 束流虚空输出仓 | 装在多方块的束流输入位，按设定的粒子种类与通量发束流；可跟随机器配方启动（配束流合成器），也可跟随红石信号启动 |
| 束流倍流器 | 把束流按设定倍数翻倍，前入后出，扳手调方向 |

- 绑定：闪存（GT 数据棒）左键存储器、右键仓 / 输入室。
- 存储器带 UUID：拆走换个地方放，所有仓会自动重新连上，不用一个个重绑。
- 输出仓能量按 eV 填（内部换算 keV），聚焦固定 99；一种粒子一个输出仓（配方要两种就放两个）。

### AE 输出加速（输出总线 / 输出仓）

GT 的 ME 输出总线、输出仓默认每 2 秒才往网络里推一次（`refreshTime` 的 40 tick 是写死的下限，游戏里既没有配置也没有命令能改小），所以下单的东西要等一两秒才看得见。

ElinarCurios 在「机器正在干活 + 这张 AE 网有玩家下的合成单」两个条件同时成立时，改成**每 tick** 刷出，小订单基本 1 秒内到账；机器停手后回到 GT 自己的 2 秒兜底，不影响正常吞吐。

- 只认玩家单：终端、ECO 合成确认框、GTNL 量子计算机下的单都算；AE2FC 库存维持器这类机器单不触发
- 配置：`meOutFastFlushEnabled`（默认开）、`meOutFastFlushHoldTicks`（默认 100 = 停手后 5 秒尾巴）
- 命令：`/Elinar meflush` 查看开关、尾巴长度和最近一次命中的网络/机器数

## 号段迁移（v1.0.0c2 起）

2026-11-14 起 TST 0.8.1 占用了 `19082/19083`，与本模组的旧号段冲突（同装会启动崩）。全部机器已整段搬到 `23100-23112`：

| 旧号 | 新号 | 机器 |
|---|---|---|
| 19082 | 23100 | 天玄虚空能量节点 |
| 19083 | 23101 | 可调式流体输入仓 |
| 19084 | 23102 | 综合采掘工厂 |
| 19085 | 23103 | 样板总成侦测器 |
| 19086 | 23104 | 束流倍流器 |
| 19087 | 23105 | 束流虚空输入仓 |
| 19088 | 23106 | 束流虚空存储器 |
| 19089 | 23107 | 束流虚空输出仓 |
| 19090 | 23108 | 束流虚空输入室 |
| 19102 | 23109 | 物品总成镜像 |
| 19103 | 23110 | 流体总成镜像 |
| 19104 | 23111 | 高级放射仓 |
| 32030 | 23112 | 高级装配线 |

**升级路线**

- 已经是 `v1.0.0c2a` 的用户（存档迁移过了）：直接用 `v1.0.0c3`，机器按新号加载。
- 还停在 `v1.0.0c1` 或更早（机器还是旧号）：**必须先装 `v1.0.0c2a` 跑一次迁移**，再换 `v1.0.0c3`。
  `c3` 不注册旧号，直接用会让旧机器变死块。

`c3` 里的命令：

- `/Elinar idmigrate` —— 修正背包/箱子/机器库存/掉落物里的旧号机器物品（AE 存储单元里的要取出后才会被修正）。
- `/Elinar idcheck` —— 列出仍是旧号的机器坐标；如果出现条目，说明这台机器已锁死，装回 `c2a` 迁移即可。

`c2/c2a` 过渡版里 NEI 会看到新旧两份同名机器；`c3` 只剩新号。

## 安装

把 `ElinarCurios-<版本>.jar` 放进整合包的 `mods` 目录。

## 构建

需要 JDK 25 运行 Gradle（产物仍是 Java 8 字节码）：

```
gradlew.bat spotlessApply build
```

产物在 `build/libs/ElinarCurios-<版本>.jar`。

## 配置

`config/ElinarCurios.cfg`。

里面还藏着几项彩蛋开关，默认关闭，翻到就知道。
